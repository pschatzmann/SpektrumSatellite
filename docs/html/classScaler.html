Detailed Description

template<class T>
class Scaler< T >

Scale from and to defined range.

The Scaler<T> class provides functionality to scale values from one range to another, and to reverse the scaling (de-scale). It is designed to be used with numeric types (such as int, float, or float) and is useful for mapping input values (e.g., sensor readings) to output ranges (e.g., actuator commands).
