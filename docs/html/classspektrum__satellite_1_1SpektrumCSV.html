Detailed Description

template<class T>
class spektrum_satellite::SpektrumCSV< T >

CSV serialization helper for SpektrumSatellite channel data.

This utility converts channel values to a single CSV line and can parse a CSV line back into a SpektrumSatellite instance.

Template Parameters
TChannel value type used by SpektrumSatellite (e.g. uint16_t, float).
