Detailed Description

template<class T = uint16_t, class ScalerT = Scaler<T>>
class SpektrumSatellite< T, ScalerT >

Spektrum Satellite protocol API.

Provides bind support, frame receive/transmit, channel access, optional scaling, protocol mode handling (1024/2048), and optional logging.

Template Parameters
TPublic channel value type (e.g. uint16_t, int, float).
ScalerTOptional custom scaler class (default is Scaler<T>).
