Detailed Description

template<class T>
class spektrum_satellite::ScalerWithNeutral< T >

Sometimes the neutral input position is not exactly the the middle of min and max. We allow the definition of a non central neutral position:

e.g. a Joystick sends values between 0 and 100 - but if the joystick is not touched we receive 55

Can be used as ScalerT of SpektrumSatellite: call setNeutral() via getScaler() to define the neutral input position.
